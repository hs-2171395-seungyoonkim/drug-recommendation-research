# SafeDrug 급성 attention 실험 보고서 (2026-09-09 갱신)

## 1. 목적

SafeDrug의 방문 표현은 진단·시술 코드 임베딩의 단순 합산이라 이번 입원의 급성 이유가 만성 배경과 구분되지 않는다. 이 실험은 그 합산 자리만 attention 풀링으로 바꾼다. query는 입원 시점 텍스트(ADMISSIONS의 DIAGNOSIS 열 + 퇴원요약 주 증상 절, Bio_ClinicalBERT 임베딩)이고, key는 코드 임베딩에 시간적 신규성(이전 입원에 없던 코드 / 있던 코드 / 이력 없음)을 더한 것이며, S3는 입원 첫 24시간 검사 30항목의 분위 구간을 query에 추가한다. 나머지(방문 GRU, 분자 인코더, DDI 손실, 학습 설정, 시드)는 원본과 동일하다. 평가는 기존 군집별 프로토콜(long k=10 보정 Jaccard 격차, 초과 DDI 격차)을 그대로 쓴다.

## 2. 절제 구성

| 변형 | query | key | 비고 |
|---|---|---|---|
| S0 | 없음(원본 합산) | 없음 | 기존 기준 덤프 재사용. S0 경로가 원본과 비트 단위로 같음을 테스트로 확인 |
| S1 | 텍스트 | 코드 | |
| S2 | 텍스트 | 코드 + 신규성 | 주 변형 |
| S3 | 텍스트 + 검사 | 코드 + 신규성 | 원본에 없던 입력이 들어감 |

신규성은 실제 입원 시각(ADMITTIME) 순서로 정의했다. SafeDrug의 기록 순서는 인접 방문 쌍의 50.0%에서 시간순과 어긋난다(6,350명 중 46.6%만 전 방문이 시간순). 이는 원본 SafeDrug의 GRU가 절반의 환자에서 뒤섞인 이력을 본다는 뜻이며 논문에 주의사항으로 적을 가치가 있다.

## 3. v1 결과 (시드 0, test)

| 변형 | Jaccard | F1 | DDI율 | 보정 Jaccard 격차 (p) | attention 정규화 엔트로피 |
|---|---|---|---|---|---|
| 기준 | 0.508 | 0.665 | 0.062 | 0.052 (0.044) | – |
| S1 | 0.505 | 0.663 | 0.060 | 0.053 (0.019) | 0.999 |
| S2 | 0.509 | 0.666 | 0.056 | 0.053 (0.040) | 0.998 |
| S3 | 0.454 | 0.616 | 0.060 | 0.064 (0.002) | 0.132 |

- S1·S2의 attention은 균등 분포였다(엔트로피 ≈ 1, 최대 가중치가 균등값의 1.2배, 주진단 적중률 hit@1 5.5%). 따라서 S1·S2는 평균 풀링 + 잔차로 학습된 것이고 결과가 기준과 같은 것은 당연하다.
- S3의 attention은 반대로 한 코드에 붕괴했다(엔트로피 0.13). 검사 query 항의 크기가 텍스트 항의 7배라 잔차와 attention을 모두 지배했다.
- 원인은 파라미터화다. key로 쓴 코드 임베딩의 크기가 0.46, query 크기가 약 2이고 이를 8로 나누므로 로짓이 0.12 이하가 되어 softmax가 평평해진다. LayerNorm과 key 사영이 없고 온도가 고정되어 있었다.
- 결론: v1은 가설 검증이 아니다. 설계한 attention이 작동하지 않았다.

## 4. v2 (파라미터화 수정)

query 합에 LayerNorm, key에 사영(W_k)과 LayerNorm, 풀링 벡터에 코드 수를 곱해 균등 attention이면 원본 합산과 정확히 같아지도록 하고, 텍스트 잔차는 0에서 시작하는 학습 게이트 g로 넣었다. 스모크 학습(2 epoch, 200명)에서 정규화 엔트로피 0.583, 최대 가중치가 균등값의 6.5배로 attention이 날카로워질 수 있음을 확인했다.

### 4.1 v2 결과 (시드 0, test)

| 변형 | Jaccard | F1 | DDI율 | 보정 Jaccard 격차 (p) | 원시 격차 변화 [95% CI] | 초과 DDI 격차 k10 / CCS | attention 엔트로피 | 게이트 g |
|---|---|---|---|---|---|---|---|---|
| 기준 | 0.508 | 0.665 | 0.062 | 0.052 (0.044) | – | 0.028 / 0.055 | – | – |
| S1v2 | 0.517 | 0.673 | 0.063 | 0.071 (0.002) | +0.018 [−0.009, 0.035] | 0.034 / 0.061 | 0.986 | 0.12 |
| S2v2 | 0.518 | 0.674 | 0.060 | 0.069 (0.001) | +0.027 [0.007, 0.042] | 0.031 / 0.061 | 0.998 | −0.07 |
| S3v2 | 0.515 | 0.672 | 0.062 | 0.057 (0.017) | +0.007 [−0.013, 0.026] | 0.031 / 0.066 | 0.998 | −0.09 |

시드 반복 규칙(보정 격차 0.015 이상 감소 또는 p > 0.05)에 해당하는 변형은 없다.

attention 검증: 주진단 hit@1은 S1v2 8.7%, S2v2 7.5%, S3v2 7.4%(균등 attention의 기대치 수준), 주진단에 실린 가중치 0.076~0.078. 세 변형 모두 attention이 급성 이유를 찾지 않는다.

군집별 보정 Jaccard 변화(기준 대비, S1v2 / S2v2 / S3v2): 심부전+당뇨 PAD +0.016 / +0.015 / +0.012, 심부전+CKD +0.019 / +0.015 / +0.010, CAD·MI +0.019 / +0.015 / +0.008, 수술합병증 +0.005 / +0.012 / +0.007, 전이암 +0.007 / +0.012 / +0.003; 호흡부전·폐렴 0.000 / −0.002 / +0.003(가장 낮은 군집); 알코올성 간질환 +0.001 / −0.013 / −0.003.

해석:
- 입원 시점 텍스트는 전체 정확도를 올린다. S2v2의 Jaccard 0.518은 지금까지 열 개 변형 중 가장 높고 DDI율 상승 없이 얻은 값이다.
- 그러나 격차는 줄지 않는다. S1v2·S2v2는 이득이 심혈관·신장 군집에 몰리고 가장 낮은 호흡부전·폐렴 군집은 그대로라 범위가 넓어지며(S2v2는 유의), S3v2는 이득이 고르게 퍼져 격차가 유지된다. 어느 변형도 격차를 줄이지 않았다.
- attention은 학습이 끝나면 다시 균등해진다. 스모크에서 날카로웠던 attention이 50 epoch 뒤 균등으로 수렴한 것은, 처방 예측 목적함수가 "급성 이유에 집중"을 보상하지 않고 평균 풀링을 선호한다는 뜻이다. 향상은 attention이 아니라 게이트 잔차(텍스트 벡터 자체)에서 왔다.
- 따라서 "급성 attention"을 실제로 만들려면 목적함수 밖의 지도 신호가 필요하다. 주진단 코드(비용 0)에 대한 보조 손실이 다음 설계다.

## 5. 결론

1. 입력 표현을 입원 시점 텍스트·신규성·검사로 보강하면 SafeDrug의 전체 성능은 오르지만(최대 +0.010 Jaccard) 군집 간 격차는 어느 변형에서도 줄지 않고, 텍스트만 넣은 경우에는 오히려 유의하게 넓어진다. 앞선 아홉 개 개입(A, B, C, C′, C″, E 세 변형)과 같은 방향의 결과이며, 격차가 표현 부족이 아니라 구조적이라는 감사 논문의 주장을 강화한다.
2. 자유 attention은 급성 이유를 찾지 않는다. 처방 목적함수만으로는 attention이 균등으로 수렴하므로, 급성 attention은 지도가 있어야 성립한다. 이는 "왜 SafeDrug가 급성 이유를 못 보는가"에 대한 답이기도 하다. 학습 신호가 그것을 요구하지 않는다.
3. 부산물로 SafeDrug 전처리의 방문 순서가 절반의 환자에서 시간순이 아님을 확인했다.

## 6. 지도된 급성 attention (S2s, 2026-09-09)

v2의 S2(텍스트 query + 신규성 key)에 보조 손실을 더했다. 학습 방문의 주진단(SEQ_NUM 1, 학습 방문의 89%에서 진단 목록 안에 존재)에 실린 attention 질량의 음의 로그를 μ배로 더한다(`--attn-supervision seq1 --attn-sup-weight μ`, 커밋 5ef3a8c).

| 변형 | Jaccard | F1 | DDI율 | 보정 Jaccard 격차 (p) | 초과 DDI 격차 k10 | attention 엔트로피 | 주진단 hit@1 / hit@3 |
|---|---|---|---|---|---|---|---|
| 기준 | 0.508 | 0.665 | 0.062 | 0.052 (0.044) | 0.028 | – | – |
| S2v2 (지도 없음) | 0.518 | 0.674 | 0.060 | 0.069 (0.001) | 0.031 | 0.998 | 0.075 / 0.207 |
| S2s μ=1 | 0.491 | 0.650 | 0.061 | 0.064 (0.007) | 0.035 | 0.244 | 0.563 / 0.794 |
| S2s μ=5 | 0.493 | 0.651 | 0.062 | 0.063 (0.007) | 0.042 | 0.254 | 0.563 / 0.794 |

- **attention은 급성 이유를 찾게 되었다.** 주진단으로 지도하자 test 방문 주진단 hit@1 0.563·hit@3 0.794(지도 전 0.075·0.207), 엔트로피 0.998 → 0.24~0.25. 즉 "급성 attention"은 만들 수 있다.
- **그러나 처방 정확도는 떨어진다.** Jaccard가 기준보다 0.017, S2v2보다 0.026 낮다. 방문 벡터가 주진단 쪽으로 쏠리면서 만성 배경 코드의 정보가 줄어들고, 처방의 대부분을 차지하는 만성 약물 예측이 나빠진다. μ를 1에서 5로 올려도 같다.
- **격차는 줄지 않는다.** 보정 Jaccard 격차 0.063~0.064, 초과 DDI 격차도 넓어진다.

해석: 처방 예측에서 "급성 이유"는 정보의 일부일 뿐이고 만성 배경이 처방의 대부분을 결정한다. attention을 급성 이유에 강제로 모으면 해석 가능성은 얻지만 정확도와 공정성은 잃는다. 급성 attention을 예측에 쓰려면 급성 풀링과 전체 합산을 나란히 두는 두 갈래 구조가 필요하고, 그 경우 attention은 설명용이지 격차 개선 장치는 아니다. 시드 반복 규칙에 해당하지 않아 시드 1~3은 돌리지 않았다.

## 7. 결론 (갱신)

1. 입력 표현을 보강해도(텍스트·신규성·검사, 지도 없는 attention) 군집 간 격차는 줄지 않는다. 열한 번째 변형까지 일관된다.
2. 지도하면 attention은 급성 이유를 정확히 가리키지만(주진단 hit@3 79%), 그 대가로 정확도가 떨어지고 격차는 넓어진다. 처방 손실은 급성 이유 집중을 보상하지 않을 뿐 아니라 그것과 충돌한다.
3. 따라서 "급성 attention"은 설명 도구로는 성립하고 공정성 개선 장치로는 성립하지 않는다. 정확도 축 격차는 여전히 출력 쪽 구조(다수 처방 사전분포)의 문제로 남는다.
