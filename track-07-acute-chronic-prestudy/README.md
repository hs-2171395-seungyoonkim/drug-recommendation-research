# 트랙 07 — 급성/만성 분리 제안서 사전검증과 처방 이력 기준선 비교

"진단을 급성/만성으로 나눠 인코딩하면 처방 **변화**(추가·중단)를 더 잘 맞힐 것이다"라는 제안서
([`docs/급성만성_분리_제안서.md`](docs/급성만성_분리_제안서.md))를 구현하기 전에,
GPU 없이 확인할 수 있는 전제부터 MIMIC-III와 MIMIC-IV 양쪽에서 검증한 기록입니다.
결론을 먼저 말하면 **제안서의 핵심 가설은 세 번의 독립 검증에서 모두 반증되었습니다.**
그 과정에서 모델이 정말로 못 하는 일이 무엇인지가 드러났습니다.

## 결과 요지

**1. "모델이 직전 처방 복사를 못 넘는다"는 전제는 데이터셋에 따라 달랐습니다.** 비교는 test 전이(직전 방문이 있는 방문) 기준입니다.

| | MIMIC-III (4 seed) | MIMIC-IV (5 seed) |
|---|---|---|
| copy-previous Jaccard | 0.4691 | 0.4431 |
| SafeDrug Jaccard | 0.5136 | 0.4398 |
| Δ(모델 − 복사) [95% CI] | **+0.045** [+0.035, +0.054] | −0.003 [−0.008, +0.001] |

처방이 정확히 그대로 유지되는 경우가 0~0.4%라서 continuation/change 이진 분류는 쓸 수 없었습니다.
그래서 변화 크기 구간으로 층화했고, 두 데이터셋 모두 변화가 작은 층에서는 복사가 모델을 크게 앞섰습니다.

**2. 급성 라벨(HCUP CCI)은 추가 약물 수와 상관(ρ ≈ 0.34)하지만 모델 오류와는 맞지 않았습니다.**
- 모델이 놓치는 추가 약물(누락률 48%)은 신규 급성 진단 수와 상관없이 평평했고, 급성 진단이 많은 방문에서 오히려 덜 놓쳤습니다(보정 β −0.073).
- 중단 쪽도 같았습니다. 해소된 진단 → 약물 중단 상관이 급성 0.298, 만성 0.279로 구분되지 않았습니다.
- 누락을 설명하는 것은 직전 약물 수였고, 이것도 약물 희귀도를 넣으면 사라집니다(β +0.238 → −0.029, R² 0.07 → 0.42).
  **핵심 약점은 롱테일 약물 recall**이며, 트랙 04의 "드문 약을 쓰는 군집에서 더 틀린다"(r +0.71)와 같은 현상입니다.
- 단서: MIMIC-IV test 전이의 11.6%는 ICD-9→10 전환 구간이라 모든 진단이 "신규"로 잡힙니다.
  이 전이를 뺀 재계산 전까지 급성 트랙의 최종 종결은 보류해 두었습니다.

**3. 처방 이력을 입력으로 받는 모델도, 검색 기준선도 이 약점은 못 고쳤습니다.** (MIMIC-IV test 전이 Jaccard)

| 방법 | Jaccard |
|---|---|
| SafeDrug | 0.440 |
| MICRON (재현, 3 seed) | 0.440 |
| copy-previous | 0.443 |
| GAMENet (재현, 3 seed) | 0.449 |
| kNN 검색 + 복사 (k = 100) | 0.449 |
| **kNN 검색 + 직전 처방 가중 (λ = 0.2)** | **0.494** |

단순 검색 기준선이 학습 모델을 크게 앞섰습니다. 그런데 다섯 방법 모두 **추가 약물 누락, 중단 판단, 드문 약 추가**는
고치지 못했습니다. 이력 입력이 붙잡는 것은 흔한 유지 약물뿐이었습니다. 구조적 원인도 확인했습니다.
SafeDrug의 `forward`는 직전 처방을 입력으로 받지 않습니다.

**4. 부수 발견**: SafeDrug MIMIC-III 전처리는 방문을 HADM_ID 순으로 둡니다(전이의 50%가 시간 역행).
시간순 records를 새로 만들어 다시 학습해 보니 정확도 차이는 −0.001로 영향이 없었습니다.

다음 방향은 [`results/next_direction_recommendation_2026-09-25.md`](results/next_direction_recommendation_2026-09-25.md)에 정리했습니다.
"SafeDrug 계열 벤치마크 현실 점검" 평가 연구를 1순위로 두고, 디코딩 조건을 맞춘 공정 비교를 필수로 넣었습니다.

## 구성

| 경로 | 내용 |
|---|---|
| `scripts/` | 전이 분리 집계, 급성 라벨 상관, 모델 오류 분해, GAMENet·MICRON 학습/덤프 래퍼, kNN 검색 기준선, 시간순 records 생성 |
| `tests/` | 공통 로직 단위 테스트 (`py -3.12 -m pytest tests`) |
| `results/` | 분석별 집계 결과(`*.md` 사람용, `*.json` 기계용) |
| `docs/` | 제안서, 09-16~18 종합보고(DDI 페널티 가설 Part 1은 트랙 06과 연결) |
| [`README_작업기록.md`](README_작업기록.md) | 분석 (A)~(M) 단계별 상세 기록과 무결성 검사 |

`out/`(방문별 예측 덤프, 재정렬 records, 체크포인트)과 `logs/`는 행 단위 MIMIC 파생물이라 올리지 않았습니다.
MIMIC-IV 쪽 입력은 트랙 03 파이프라인의 final5 records로 학습한 SafeDrug 5시드 체크포인트에서 추론했습니다(트랙 03 공개본에는 final4 스모크까지만 있습니다).
