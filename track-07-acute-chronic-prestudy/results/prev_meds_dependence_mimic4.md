## 해석

- 직전 약물 수가 1–8개에서 18–49개로 가면 added 누락률(@0.5)은 0.405 → 0.595. 같은 구간에서 size gap(예측 − 정답)은 2.94 → 0.53, 예측 중 직전 약물 비율 0.411 → 0.751, 예측 신규 수 7.32 → 4.33(실제 added 4.90 → 3.68).
- **희귀도가 의존성을 설명한다 (M4).** 큰 처방에 추가되는 약물은 학습셋에서 드물다(added 평균 학습 빈도 0.345 → 0.207). added 약물의 학습 빈도를 회귀에 넣으면 n_prev 계수가 0.238 [0.215, 0.260] → -0.029 [-0.045, -0.010]로 사라지고, R²는 0.070 → 0.421. 학습 빈도 계수 -0.644가 압도적이다. added 약물의 평균 확률도 같은 구조다(빈도 계수 0.662, n_prev 0.017).
- oracle 크기(정답 개수만큼 뽑기)에서는 누락률 0.462 → 0.565이지만, 보정하면 n_prev 계수는 -0.131 [-0.150, -0.113]로 음수이고 대신 **stopped 수**가 0.307로 크다. 즉 큰 처방에서 순위가 나빠지는 것이 아니라, 중단됐어야 할 약물이 상위 순위를 차지해 added 자리를 뺏는다(stopped 약물 평균 확률 0.489~0.358 vs added 0.390~0.553; stopped 제거율은 0.478~0.645에 그친다).
- 디코딩 크기(M1)는 부차적이다. size gap은 작은 처방에서 +2.9(과다 예측), 큰 처방에서 +0.5로 임계 0.5가 작은 처방을 과다 예측하는 쪽의 문제이고, 임계를 0.3으로 낮춰도 n_prev 계수는 0.234로 그대로다.
- 임계값을 0.3으로 낮추면 최대 구간 누락률 0.595 → 0.480, Jaccard 0.452 → 0.452 (최소 구간 Jaccard 0.426 → 0.409). 전역 임계 하나로는 구간별로 득실이 갈린다.
