# SafeDrug 군집별 추천 성능 요약 (2026-09-04)

SafeDrug(IJCAI'21 공개 코드)를 MIMIC-III SafeDrug 코호트로 50 epoch 학습(시드 4개)하고, test 분할 방문별 추천 결과를 사전에 고정한 진단 텍스트 군집(long k=10)별로 평가했다. 평가 지표는 방문별 Jaccard(실제 처방 집합 vs 추천 집합). 보정 = 진단 수·실제 약물 수·방문 순서를 회귀로 통제한 값. p = 환자 단위 순열 검정 1만 회, Bonferroni(분할 5개) 보정.

## 4. k 선택

k=2~50(42개 구성)을 훑고 선택 편향을 보정했다. 군집 크기 ≥30, 시드 간 ARI ≥0.85, 보정 p<0.05를 모두 만족하는 k는 long 4~10이며, 그중 가장 큰 10을 채택했다.

## 5. 읽는 법

raw는 환자가 실제로 받는 추천 품질, 보정은 환자 복잡도로 설명되지 않는 군집 효과다. 둘이 같은 방향이고 보정 후에도 격차가 남으며 시드에 걸쳐 재현되므로, SafeDrug의 추천 품질과 안전성이 임상군에 따라 균일하지 않다는 근거가 된다. 격차 크기는 전체 평균 대비 약 12%다.
